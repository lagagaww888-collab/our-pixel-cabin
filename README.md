# 我们的像素小屋

一间可以用键盘探索的双人像素木屋。走到家具旁按 E 写日记、读信、打开相册，或和屋里的角色打招呼。每位访客的私人记录保存在自己的浏览器中。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，分支选 main，目录选 /(root)。首页使用相对路径，可以部署在仓库名称对应的子目录下。

## 在 Windows 打开

将完整项目解压到固定文件夹，双击 index.html，用 Microsoft Edge 打开。项目使用原生 HTML、CSS 和 JavaScript，图片随项目提供，首次运行也可以离线。请保留 assets、data、js 与入口文件的相对位置。

也可以在项目文件夹运行 `py -m http.server 8765 --bind 127.0.0.1`，再访问 `http://127.0.0.1:8765`。以后请用相同浏览器、配置文件和打开方式访问。移动目录或从双击切换到本地服务器之前，先导出备份。

## 在屋里走动

| 操作 | 键鼠 |
|---|---|
| 移动 | WASD 或方向键，同时按两个方向可斜走 |
| 奔跑 | 按住 Shift 并移动 |
| 前往地板上的位置 | 鼠标左键点击，角色绕开家具占地 |
| 家具或访客互动 | 靠近后按 E，也可直接点击 |
| 互动菜单 | 空地上按 E，或在房间按 Esc |
| 关闭面板 | Esc 或右上角 × |
| 表情与身体动作 | 1 开心、2 害羞、3 惊喜、4 思考、5 委屈，兼容小键盘 |
| 坐下休息 | 在地毯中部停留约 9 秒，移动会起身 |

银时、新八、神乐、定春、伊丽莎白都在地板上独立来回走动。靠近会停步，可以与每位角色说话、回应。左侧玻璃柜上层陈列 NewJeans × 飞天小女警五位成员和白兔，中层为兔子手办，下层为唱片与应援物。打开下层后选择「查看专辑封面」，可查看专辑封面原图。收藏卡保留素材包里的 cameo。

右上角「全屏游玩」可按屏幕比例展开房间，点「退出全屏」或按 Esc 返回。窗边花架可以浇水，电脑桌上方的信箱可读信。左侧阅读椅上的轻松熊支持点击或靠近按 E 对话。

## 写下自己的内容

- **日记本和信箱**可建立、阅读、修改、删除带日期的记录。信件保存在这台电脑，两个人可以轮流打开小屋读信。
- **照片墙**可添加本地照片，填写标题、日期和故事并保存。点照片放大，再点还原。上一张、下一张切换，删除时需要确认。
- **礼物盒**提供两个可替换的占位礼物。「小屋设置 → 编辑礼物」可修改名称与留言、增删礼物。打开状态随小屋保存。
- **电脑桌**收录纪念日、目标、留言及抽屉彩蛋。**盆栽**会随浇水长大。**床铺**可熄灯入睡，移动或再次点击床铺起床。
- **小屋设置**可改双方昵称、小屋名、欢迎语、纪念日、昼夜，也可显示通用男主占位角色。
- **八音盒**内置《Jump Up, Super Star!》八音盒版，署名为久保直人、辻勇旗。打开页面会尝试有声循环播放。若浏览器要求先互动，按移动键或点击页面即可启动。可暂停、静音、调节音量和进度，也可导入其他本地曲目并移除以恢复主题曲。

## 保存与恢复

设置、文字记录、礼物状态和浇水次数写入此浏览器的 localStorage，键名为 our-pixel-cabin-v1。照片及音频以 Blob 存在 IndexedDB 的 our-pixel-cabin-media 数据库、files 对象仓库中。所有媒体处理均在本机进行。

在「小屋设置 → 导出完整备份」保存 JSON。换电脑时打开项目，选择「从备份恢复」，选取 JSON 并确认替换。备份中包括照片、音频和私人文字，文件大小随媒体增加。清空需要两次确认。浏览器隐私模式、清理站点数据或更换打开地址会影响数据可见性。

## 修改代码与素材

- data/config.js 集中声明图片路径、默认个人设置、礼物、家具名称和命中区域。修改默认值主要影响新建小屋，已有小屋通过设置更新。
- data/visitors.js 配置访客大小、路线、对话和回应。坐标以 560 × 252 的设计网格计算，以脚底作为角色位置。
- js/scene.js 负责女主动作、表情、昼夜与家具布局。js/navigation.js 记录家具占地和点击寻路。js/visitors.js 驱动来访角色。
- js/panels.js、media.js、settings.js、storage.js 分别管理家具面板、相册与播放器、设置与备份、浏览器存储。
- 替换女主请保持同一套造型、透明 PNG 与一致的脚底基准。ASSETS 中 front、back、left、right 对应四方向，walk、run、sit、sleep 为动作，happy、shy、surprised、thinking、upset 为表情。男主只需替换 boy 的资源映射。
- assets/album-cover.png 是应援角展示的专辑封面。assets/shelf.png 是场景柜体，tier0、tier1、tier2 是三层放大图。更换封面时也应更新柜体和下层放大图中的封套。
- 新家具、柜体和木墙使用内置 ImageGen 生成独立素材后拼装。美术提示围绕胡桃木三层玻璃柜、暖灯、五位联名造型与白兔、夜樱窗、粉色拼布床和复古茶桌。女主与银魂角色来自确认设定板或素材包。原 ZIP 未修改。

参见「素材检查.md」与「测试结果.md」。
